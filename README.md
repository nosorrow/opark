# OPark — Публичен уебсайт

Публичен уебсайт за **OPark** — услуга за управление на наеми за паркоместа и гаражи с онлайн картови плащания.

## Структура на проекта

```
opark.bg/
├── index.html                    # Начална страница (всички секции)
├── usloviya.html                 # Условия за ползване
├── plashtaniya-i-vrashtane.html  # Плащания и връщане
├── poveritelnost.html            # Политика за поверителност
├── assets/
│   ├── css/
│   │   └── styles.css            # Tailwind CSS v4 + дизайн система
│   ├── js/
│   │   ├── theme.js              # Управление на тема (светла/тъмна)
│   │   └── main.js               # Основен JavaScript (навигация, UX)
│   └── images/                   # (Резервирана директория за изображения)
├── public/
│   ├── favicon.svg               # SVG фавикон
│   ├── robots.txt                # Насоки за търсещи роботи
│   └── sitemap.xml               # XML карта на сайта
├── package.json
├── vite.config.js
└── README.md
```

## Деплой

### Обикновен уеб хостинг (препоръчан)

1. Изпълнете `npm run build`
2. Качете съдържанието на директория `dist/` в корена на `https://opark.bg`
3. Уверете се, че сървърът обслужва `.html` файлове директно

### Apache / .htaccess

При нужда от пренасочване добавете `.htaccess`:

```apache
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ /index.html [QSA,L]
```

### Nginx

```nginx
location / {
    try_files $uri $uri/ $uri.html =404;
}
```

## Светла/тъмна тема

Темата се управлява от `assets/js/theme.js`:
- Запазва избора в `localStorage` с ключ `opark-theme`
- Следва системните предпочитания при липса на избор
- Предотвратява мигане при зареждане (inline скрипт в `<head>`)
- Работи идентично на всички четири страници

## Забележки за разработчика

- Tailwind CSS v4 използва CSS-first конфигурация (`@import "tailwindcss"` + `@theme {}` + `@custom-variant`)
- Dark mode се конфигурира с `@custom-variant dark (&:where(.dark, .dark *))`
- Flowbite се импортира като ES модул в `main.js`
- Всяка страница има inline `<script>` в `<head>` за предотвратяване на мигане при зареждане
- `[data-year]` елементите се попълват динамично от JS с текущата година
- Anchor линковете от правните страници използват формата `/#section` за навигация към началната страница
